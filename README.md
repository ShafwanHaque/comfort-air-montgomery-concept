# Comfort Air Inc. — website concept

Standalone local outreach preview tailored to the business’s public branding and services.

## Run locally

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Project notes

- Prospect site: https://comfortairac.com/
- The official company logo and homepage/service image are stored locally under `public/brand` and `public/hero`.
- Business details, theme, contact information, and service areas are in `src/config/site.config.ts`. Confirm details with the business before launch.
- The contact form is a preview and does not send submissions. Map tiles need an internet connection; map pins are representative.
